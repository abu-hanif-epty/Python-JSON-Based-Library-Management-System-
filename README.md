# Python JSON Library Management System

## Project Description

This project is a simple Library Management System built with Python. The main goal of developing this project was to understand how JSON works and how to use it for storing, reading, updating, and managing data in a real-world application.

Through this project, I practiced Python's built-in `json` module, file handling, lists, dictionaries, loops, conditional statements, and exception handling. I used a JSON file to store book information so that the data could be saved and accessed even after the program was closed.

## Features

- Add new books to the library.
- View all available book records.
- Search for books by their ID.
- Store book information in a JSON file.
- Validate user input and prevent duplicate book IDs.
- Handle missing files and invalid JSON data.

## Technologies Used

- Python
- JSON
- File Handling

## Learning Objectives

The primary objective of this project was to gain practical experience with JSON data and understand how Python interacts with files to manage persistent data. This project also helped me improve my problem-solving skills and apply basic Python concepts in a practical application.
